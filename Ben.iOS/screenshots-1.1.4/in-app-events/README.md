# In-app events (App Store Connect)

One folder per event: its README holds the App Store Connect fields, `card.png` (16:9, 1920 × 1080)
and `details.png` (9:16, 1080 × 1920).

## The pictures show the platform, whatever the event is about

An in-app event on the App Store is most people's first look at the app. So the card and the details
page always show the Paranormal Platform itself: the live meter, a saved session, the Paranormal tab.
The event's name and text can be about Halloween, a season or a feature; the pictures are about the
app as a whole.

Ben, 10/27/2026: the Halloween pictures showed event screens (the Events list and a QR pass), which
is what an event looks like, not what the app does. Those stay as they were made; nothing new goes
out that way.
