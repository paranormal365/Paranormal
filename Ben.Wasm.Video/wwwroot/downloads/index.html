Sidecar — native acceleration for the video editor

The Sidecar is an optional helper you install on your own computer. When it is running, the video editor hands its heavy work — decoding, rendering, exporting — to your machine directly instead of doing it inside the browser's sandbox. Same results, considerably faster, and long projects stop straining the browser. Without it, everything in the editor still works.

It runs only on your computer and listens only to your own machine. It is not a server, and it sends nothing anywhere on its own.

These are unsigned test builds. This is a testing and verification release: the installers carry no code signature, so your operating system will warn you — and the warnings are accurate, because nothing cryptographically proves who built this software. Install it only if you were sent here by us and you trust this site. Signed builds come later.

Windows (64-bit)

BenVideoSidecar-win-x64.zip

Windows 10 or 11, x64 · about 160 MB · no administrator rights needed

Download for Windows
  1. Unzip the download somewhere — actually extract it, don't browse inside the zip.
  2. Right-click install.ps1 and choose Run with PowerShell. If that is blocked, open PowerShell in the folder and run powershell -ExecutionPolicy Bypass -File install.ps1.
  3. Expect “Windows protected your PC” the first time anything runs — click More info, then Run anyway. That prompt is what “unsigned” means. Some antivirus tools may quarantine it outright; if the sidecar vanishes after install, that is what happened.
  4. A pairing page opens showing a six-digit code. In the editor, click the sidecar chip in the toolbar and type the code in.

Installs under your own profile (%LOCALAPPDATA%\BenVideoSidecar) and starts automatically when you sign in. Remove it any time with uninstall.ps1 from the same folder.

macOS (Apple Silicon)

BenVideoSidecar-osx-arm64.dmg

macOS on M-series Macs · about 107 MB · no administrator rights needed

Download for Mac
  1. Open the downloaded .dmg.
  2. Right-click Install BenVideo Sidecar, choose Open, then click Open in the dialog that appears. Right-click rather than double-click, and the difference is not cosmetic: this build has no Apple Developer ID and is not notarized, so a double-click is refused outright with “unidentified developer” — which looks like a broken download. Opening it this way records that you chose to run it, and macOS allows it. Nothing else about the install differs.
  3. A pairing page opens showing a six-digit code. In the editor, click the sidecar chip in the toolbar and type the code in.

Everything lands in your home folder — no password is asked for, and nothing is installed system-wide. It starts automatically when you log in. To remove it, right-click Uninstall BenVideo Sidecar in ~/Applications and choose Open; the installer puts it there so you do not need this disk image again. Intel Macs: no build yet — ask and we will add one.

Good to know

  • Pairing is per browser and per site address. Open the editor in a different browser and you pair again. The code is single-use and expires after ten minutes.
  • Verifying your download: each build has a checksums file listing the SHA-256 of the installer as built — Windows · Mac. On Windows: Get-FileHash BenVideoSidecar-win-x64.zip; on macOS: shasum -a 256 BenVideoSidecar-osx-arm64.dmg.
  • Removing it changes nothing else. The editor simply goes back to rendering in the browser, which is what it does for everyone without a sidecar.
