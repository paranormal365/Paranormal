🔷 Ben — Project Analysis

Architecture reference for all 11 projects in the Ben solution.

Solution Architecture

The Ben solution is structured as a clean layered architecture:

  • Data layer: Ben.Data.Common → Ben.Data.Source → Ben.Data.WebApi
  • Service layer: Ben.Service.Mappings, Ben.Service.Models, Ben.Service.RepositoryService, Ben.Service.Security
  • UI layer: Ben.Web.Library → Ben.Web.WebApp
  • Tests: Ben.Service.RepositoryService.Tests, Ben.Web.Tests
