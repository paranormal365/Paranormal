Ben.Web.Tests — Summary

Type: xUnit Test Project
Test count: 100 tests (all passing)

Purpose

Unit tests for the Ben.Web.WebApp service layer.
Uses Moq for mocking HTTP client dependencies; no real HTTP calls or database access.

Test Files

File Tests Coverage
Services/JwtClaimsParserTests.cs ~15 JwtClaimsParser.ParseClaims — sub/role parsing, base64url decoding (fixes for -/_ chars), array role claim, edge cases
Services/WebApiTokenStoreTests.cs ~10 WebApiTokenStore — IsAuthenticated, defaults, impersonation field storage, IsEntraSession
Services/WebApiAuthServiceTests.cs ~25 WebApiAuthService.LoginAsync, Logout, ImpersonateAsync, StopImpersonating, RefreshIfNeededAsync — happy paths and failure cases
Services/EntraTests.cs ~10 Entra session flag behaviour, LoginAsync resetting IsEntraSession, token holder properties
Services/WebApiClientTests.cs 14 WebApiClient auth header injection — bearer token sent/not sent, request-time token read, HTTP verb correctness, non-2xx handling
Controllers/MeControllerTests.cs ~12 MeController.Get — OID-first lookup, local user fallback, unlinked Entra user, FormatException catch for MSA sub claim
Controllers/EntraAuthControllerTests.cs ~15 EntraAuthController.Register and Link — happy paths, duplicate OID, conflict, rollback, idempotent re-link

Testing Notes

  • Synthetic JWTs: JwtClaimsParser tests create hand-crafted JWT strings. In production, the Identity API issues opaque data-protected tokens — role is resolved via GET /api/me.
  • MoqSetup pattern: Most service tests mock IWebApiIdentityClient to return test WebApiTokenResponse objects and IWebApiClient for MeResponse.
