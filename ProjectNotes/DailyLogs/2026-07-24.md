## Known Issues / Notes

- **Bearer token expiry:** ASP.NET Core Identity data-protected tokens are invalidated when the WebApi restarts. Users must log out and back in after any WebApi restart. Entra OIDC tokens are unaffected.
- **Entra login TLS timeout:** First Entra login attempt sometimes hits a macOS/.NET SSL handshake timeout against `login.microsoftonline.com`. Retrying immediately succeeds. Transient — no code fix needed.
- **`start-web-app` task turns red:** Expected behaviour. VS Code background tasks mark as "finished" once the `endsPattern` (`Now listening on: http`) is matched. The WebApi and WebApp processes keep running.
- **File storage:** All uploads use `LocalFileStorageService` (disk at `.uploads/`). `UploadFile.FileData` is always `null` for new uploads.
- **`OrganizationClientSettings.razor`** needs a nav link added from the org management page (not done yet — next session).

### 6. `TelerikSlider` — `Step` → `SmallStep` / `LargeStep` (Telerik 14.1.0)

### 7. `TelerikTabStrip` — `ActiveTabIndex` → `ActiveTabId` (Telerik 14.1.0)
- `OrgMessages.razor` used `ActiveTabIndex` (int) which was removed in v14.x
- Replaced with `ActiveTabId="@_activeTabId"` (string) + `TabStripTab Id="inbox"/"sent"`
- Added note to docs: always use `ActiveTabId` + `TabStripTab.Id`; `ActiveTabIndex` is not a valid parameter

### 8. Area of Operation dialog — `TelerikDialog` → `TelerikWindow`
- `OrganizationClientSettings.razor` "Set Operating Area" dialog: Look Up button never enabled, Save never enabled
- Root cause: `TelerikDialog.ShouldRender()` returns false when already visible — bound fields inside `DialogContent` and `DialogButtons` do not re-render
- Fix: extracted dialog into `AreaOfOperationDialog.razor` (self-contained component) and replaced `TelerikDialog` with `TelerikWindow` + `WindowContent`. `TelerikWindow` re-renders correctly on state changes
- **Updated memory note:** Always prefer `TelerikWindow` over `TelerikDialog` for any dialog that contains interactive controls (textboxes, buttons with dynamic `Enabled`)
