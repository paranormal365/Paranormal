## Known Issues / Notes

- **Bearer token expiry:** ASP.NET Core Identity data-protected tokens are invalidated when the WebApi restarts. Users must log out and back in after any WebApi restart. Entra OIDC tokens are unaffected.
- **Entra login TLS timeout:** First Entra login attempt sometimes hits a macOS/.NET SSL handshake timeout against `login.microsoftonline.com`. Retrying immediately succeeds. Transient — no code fix needed.
- **`start-web-app` task turns red:** Expected behaviour. VS Code background tasks mark as "finished" once the `endsPattern` (`Now listening on: http`) is matched. The WebApi and WebApp processes keep running; only the task UI indicator changes state.
- **File storage:** All uploads use `LocalFileStorageService` (disk at `.uploads/`). `UploadFile.FileData` is always `null` for new uploads; `FileMigrationService` handles any legacy rows at startup.
