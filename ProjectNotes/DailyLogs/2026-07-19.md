### 3 — `TelerikWindow` `Centered` property removed in Telerik 14.1

**Symptom:** Clicking the Upload button on the Files tab threw:
```
System.InvalidOperationException: Object of type 'TelerikWindow' does not have a property matching the name 'Centered'.
```

**Root cause:** `Centered="true"` was used on the `TelerikWindow` in `AudioFilePreview.razor`. This parameter was removed in Telerik 14.1 — the window now auto-centers when `Modal="true"`.

**Fix:** Removed `Centered="true"` from `AudioFilePreview.razor`'s full-view `TelerikWindow`.

---

### 4 — File upload `ContentType` guard

**File:** `Ben.Web.WebApp/Components/Pages/UploadFiles.razor`

Added a null/empty guard for `_selectedFile.ContentType` before constructing `MediaTypeHeaderValue`. Falls back to `application/octet-stream` when the browser doesn't report a MIME type (e.g. unusual file extensions on some OS/browser combos).

---

### 5 — Admin file delete was calling non-existent route

**Symptom:** Del button in the Files tab grid did nothing (silently failed with "Delete failed." message).

**Root cause:** `BenAdminClientAdapter.DeleteUploadFileAdminAsync` was calling `DELETE /api/admin/upload-files/{id}`, which does not exist. The correct endpoint is `DELETE /api/upload-files/{id}` (in `UploadFileController`).

**Fix:** Corrected the URL in `BenAdminClientAdapter.cs`.
