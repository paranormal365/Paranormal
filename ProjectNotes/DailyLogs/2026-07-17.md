---

## Decisions

- Password fields use native HTML `<input type="password">` — `TelerikTextBox` has no password mode; Bootstrap `form-control` class keeps visual consistency.
- `[NonAction]` override on base `Create` is cleaner than adding a route prefix to `CreateUser`, keeping the REST URL as `POST /api/admin/app-users`.
