### Plan — What Needs to Happen Next

#### Step 1 — Install Docker Desktop
- Download from [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)
- Choose the correct chip (Apple Silicon M-series or Intel)
- Install and start Docker Desktop

#### Step 2 — Run SQL Server Container
Once Docker is running, execute:
```bash
docker run \
  -e "ACCEPT_EULA=Y" \
  -e "SA_PASSWORD=YourStrong@Password1" \
  -p 1433:1433 \
  --name bendb-sql \
  --restart unless-stopped \
  -d mcr.microsoft.com/mssql/server:2022-latest
```
This matches the credentials in `appsettings.Development.json`.

#### Step 3 — Generate Missing Entity Code
Copilot will create the missing generated partial class files for all 26 entities and the complete `BenDataContext`, derived from the `BenDataModel.efml` XML. Files will be named `*.Generated.cs` in the `Entities/` and `Context/` folders.

#### Step 4 — Add EF Core Design Package & Design-Time Factory
- Add `Microsoft.EntityFrameworkCore.Design` to `Ben.Data.Source.csproj`
- Add an `IDesignTimeDbContextFactory<BenDataContext>` so `dotnet ef` can create the context at design time

#### Step 5 — Create and Apply EF Core Migration
```bash
cd /Users/ben/Source/Ben

  --project Ben.Data.Source \
  --startup-project Ben.Web.WebApp
dotnet ef database update \
  --project Ben.Data.Source \
  --startup-project Ben.Web.WebApp
```

## Session Notes — Microsoft Identity Implementation

### What Was Done

#### 1. `AppUser` now extends `IdentityUser<Guid>`
- **`Ben.Data.Source/Entities/BenDataModel.AppUser.cs`** (user stub) changed to:
  ```csharp
  public partial class AppUser : IdentityUser<Guid>, IIDStd { }
  ```
- `Id` (Guid) is now provided by `IdentityUser<Guid>` — satisfies `IIDStd` without needing a separate property.
- The old `UserId: string` field (which was a manual reference to Identity) is replaced — Identity is now the authoritative source of the user record.

#### 2. `AppUser.Generated.cs` updated
- Removed the now-redundant `UserId` property (provided by `IdentityUser<Guid>` as `UserName` / `Email`).
- Removed explicit `Id` declaration (provided by `IdentityUser<Guid>`).
- Kept: `DisplayName`, `DateCreated`, `DateUpdated`, and all navigation properties.

#### 3. `BenDataContext` now extends `IdentityDbContext<AppUser, IdentityRole<Guid>, Guid>`
- **`Context/BenDataContext.Generated.cs`** base class changed from `DbContext` to `IdentityDbContext<AppUser, IdentityRole<Guid>, Guid>`.
- This brings in the ASP.NET Identity tables automatically via EF Core.
- **`Context/BenDataModel.BenDataContext.cs`** (user stub) had its `: DbContext` base class removed — base is now declared only in the generated partial.

#### 4. Identity registered in `Program.cs`
```csharp
builder.Services.AddIdentity<AppUser, IdentityRole<Guid>>(options =>
{
    options.Password.RequireDigit = true;
    options.Password.RequiredLength = 8;
    options.Password.RequireNonAlphanumeric = false;
    options.Password.RequireUppercase = true;
    options.Password.RequireLowercase = true;
    options.User.RequireUniqueEmail = true;
})
.AddEntityFrameworkStores<BenDataContext>()
.AddDefaultTokenProviders();
```

#### 5. Migrations
- `AddIdentitySchema` migration created and applied — added Identity columns to `AppUsers` and created the 6 Identity tables.
- Database now has **33 tables** total.
