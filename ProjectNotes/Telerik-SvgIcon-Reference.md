# Telerik SvgIcon Reference

The complete, ground-truth list of `SvgIcon.*` names available from `Telerik.SvgIcons` **v4.9.3** (the exact version this repo restores via `Telerik.UI.for.Blazor 14.1.0` — confirmed from `project.assets.json`). 876 icons total.

## Why this file exists

Guessing an icon name (`SvgIcon.Music`, `SvgIcon.FilmStrip`) has caused real `CS0117` build failures more than once — the name usually *sounds* right but doesn't exist. Check this list (or grep it) before writing `SvgIcon.SomeGuess` in a `Icon="@SvgIcon.X"` attribute.

**Known near-misses** (sound plausible, don't exist):
- `SvgIcon.Music` → doesn't exist. Use `MusicNotes`, or `FileAudio` for an audio *file* icon specifically.
- `SvgIcon.FilmStrip` → doesn't exist. Use `Film`, or `FileVideo` for a video *file* icon specifically.

## How to regenerate this list

If Telerik.UI.for.Blazor is upgraded, the icon set can change. Regenerate with:

```bash
mkdir -p /tmp/icon-dump && cd /tmp/icon-dump
cat > dumper.csproj << 'EOF'
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>
</Project>
EOF
cat > Program.cs << 'EOF'
using System.Reflection;
// Update the version number in this path to match whatever Telerik.SvgIcons
// version project.assets.json shows for the currently-restored Telerik.UI.for.Blazor.
var path = "/Users/ben/.nuget/packages/telerik.svgicons/<VERSION>/lib/netstandard2.0/Telerik.SvgIcons.dll";
var asm = Assembly.LoadFrom(path);
var type = asm.GetTypes().First(t => t.Name == "SvgIcon");
foreach (var n in type.GetProperties(BindingFlags.Public | BindingFlags.Static).Select(p => p.Name).OrderBy(n => n))
    Console.WriteLine(n);
EOF
dotnet run
```

To find the exact restored version: `grep -A2 '"Telerik.SvgIcons/' Ben.Web.Library/obj/project.assets.json`.

## Media / file icons (quick reference for the universal media library work)

| Icon | Use for |
|---|---|
| `File` | Generic/unknown file type |
| `FileAudio` | Audio file |
| `FileVideo` | Video file |
| `FileImage` | Image file |
| `FilePdf`, `FileWord`, `FileExcel`, `FilePpt`, `FileCsv`, `FileZip`, `FileTxt` | Specific document types |
| `Image`, `Images` | Generic image / image collection |
| `Film` | Video/movie (generic, not file-specific) |
| `MusicNotes` | Audio/music (generic, not file-specific) |
| `Microphone`, `MicrophoneOutline`, `MicrophoneSolid` | Recording/audio input |
| `Play`, `PlaySm`, `Pause`, `PauseSm`, `Stop`, `StopSm` | Transport controls |
| `VolumeUp`, `VolumeDown`, `VolumeMute` | Audio level |
| `Folder`, `FolderOpen`, `FolderAdd`, `FolderMore`, `FolderUp` | Folder/navigation |
| `Upload`, `Download`, `DownloadLight` | File transfer |
| `Camera` | Photo capture |
| `Paperclip`, `PaperclipAlt`, `PaperclipOutline` | Attachments |
